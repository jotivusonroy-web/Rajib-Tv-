# RAJIB TV 📺

**Premium Live TV Streaming Interface**

A modern, responsive, static IPTV web application that parses an M3U/M3U8 playlist and turns it into a beautiful streaming platform with categories, search, favorites, recently watched, and an integrated HLS video player.

---

## ✨ Features

- 🎬 **Full M3U/M3U8 playlist parsing** — automatically detects channel name, logo, group-title, tvg-name, tvg-id
- 🗂️ **Auto-generated categories** — Sports, News, Bangla, Movies, Music, Kids, Documentary, Religious, Entertainment, International, and more
- 🔍 **Instant search** — search by channel name, category, or tvg-name
- ⭐ **Favorites** — saved in browser localStorage, no login required
- 🕘 **Recently Watched** — automatically tracked (last 20 channels)
- ▶️ **Built-in HLS player** using hls.js with graceful error handling
- 🎨 **Premium dark UI** — glassmorphism, glowing borders, animated background, purple/blue/cyan gradients
- 📱 **Fully responsive** — mobile, tablet, desktop, large desktop
- ⚡ **Performance optimized** — paginated rendering, lazy images, event delegation
- 🔒 **Safe** — no `eval()`, no server, no tracking
- 🌐 **GitHub Pages compatible** — 100% static
